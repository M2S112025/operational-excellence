## Reproduction and evidence notes

- Long-item fixture is explicitly synthetic and valid for the existing model: an item description with an unbroken serial identifier. No persisted model format was changed.
- Original baseline ran 26 URL/state entries at nine widths (234 combinations); eight width tests failed and 1920 passed. Error, geometry, screenshot and trace evidence is preserved. Later targeted reproductions exposed interaction, long-content, naming and sticky defects.
- The initial nested-dropdown Escape suspicion was a harness artifact: full-page modal screenshots/programmatic background scrolling interfered with live focus. Modal screenshots now capture the viewport, background scrollers are not manipulated while a popup is open, and finite entrance animations settle before measurement. Regression still requires Escape to close the dropdown while retaining its editor. No production dropdown workaround was applied.
- The initial tooltip locator failure included a visible explanation but no tooltip role. A subsequent stable description-linkage assertion exposed that hover-then-click closes the popup; an earlier visibility-only check had read its exit animation. The click now keeps the explanation open, and semantics/sizing are repaired.
- P0 QR test initially failed because the baseline storage snapshot preceded normal global Action attention/fixture initialization. Added a readiness precondition; exact before/after equality remains. No business behavior was modified to satisfy the test.
- [Ownership overflow geometry](ui-evidence/linked-owner-before-geometry.json) and [linked ownership/tooltip failure trace](ui-evidence/linked-owner-tooltip-before-trace.zip) preserve the stricter final reproduction.
- Historical P0 authorization acceptance failures remain unchanged and visible. They are not UI defects and are outside this task's fixes.

Batch 2 modules and compatibility routes remain pending by the requested execution sequence. This register is not an application-wide completion claim.
